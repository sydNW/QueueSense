\# QueueSense



A mobile app that predicts hospital waiting times using a Random Forest regression model.



\## Structure

\- `android-app/` - Android app (Kotlin, Jetpack Compose)

\- `backend/` - FastAPI service that serves the ML model, backed by PostgreSQL

\- `ml/` - notebooks and training work

\- `docs/` - proposal, wireframes and slides
